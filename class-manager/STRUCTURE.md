# Class Manager: structure

Version 0.7.0, written 10 November 2026 from `main` at commit 25f153b. This is the file map: what each file is, who uses it and which server actions it calls. How the parts work together (deployment modes, data model, flows, statistics, security, release) is in [ARCHITECTURE.md](ARCHITECTURE.md). This document replaces the review notes of 9 November 2026, which described the package before access codes, statistics, groups, the calendar, messages, the attendance safeguards and the teaching features.

## Folder map

```
class-manager/
  config.js                  window.CM: course labels and scriptUrl (generated by the desktop app)
  index.html                 student portal
  course.html                lectures: the weekly programme
  mock-exam.html             mock examination
  quiz.html                  live quiz, student
  quiz-host.html             live quiz, lecturer controls
  quiz-display.html          live quiz, projector
  attend.html                attendance check-in, student (opened by the QR code)
  attendance.html            attendance session and review, lecturer
  lecturer.html              lecturer sign-in and menu
  control.html               Control Centre
  codes.html                 access codes and printed slips
  insights.html              teaching insights
  groups.html                student groups and projector view
  outcomes.html              questions linked to learning objectives
  assignments.html           group assignments, lecturer
  group-work.html            group work, student
  calendar.html              course calendar
  messages.html              messages and announcements
  sw.js, manifest.webmanifest  installable portal
  assets/                    shared CSS and JS, QR code library, KaTeX, icons
  data/                      lectures.json, portal.json, pages/course.json, site.json (empty course)
  templates/                 lecture.html, practice.html (lecture-N.html and lecture-N-practice.html are made from these)
  apps_script/               quiz_receiver.gs (the server script), live_quizzes.json
  course-packs/phys143/      PHYS 143 as a course pack source: course.json, files/, tools/ (not shipped)
  preview-pedagogy/          screenshots of the 0.7.0 teaching features
  desktop/                   the Electron app (below)
  README.md, STRUCTURE.md, ARCHITECTURE.md
```

## Pages

| Page | Audience | Credential | Server actions used |
|---|---|---|---|
| `index.html` | Students | None; My progress needs ID and access code | `portal_status`, `my_results`, `announcements`, `calendar`, `chat` (unread count) |
| `course.html`, `lecture-N.html`, `introduction.html` | Students | None | None (reads `data/*.json`) |
| `lecture-N-practice.html`, `introduction-practice.html` | Students | Optional ID | POST `attempt`, `report` |
| `mock-exam.html` | Students | Optional ID | POST `attempt` |
| `quiz.html` | Students | Join code, first name, ID | `status`, `questions`, `review`, `ranking`, `result`, `attend`; POST `join`, `answer`, `progress` |
| `attend.html` | Students | ID and access code, rotating QR token | `attend` |
| `group-work.html` | Students | ID and access code | `group_work` |
| `messages.html` | Students and lecturer | ID and access code, or host key | `chat`, `announcements`, `calendar`, `hostcheck` |
| `calendar.html` | Students and lecturer | None; host key to edit | `calendar`, `calendar_ics`, `calendar_edit`, `set_week`, `hostcheck` |
| `quiz-display.html` | Projector | Join code | `display`, `questions` |
| `lecturer.html` | Lecturer | Host key | `hostcheck` |
| `control.html` | Lecturer | Host key | `version`, `portal_status`, `preclass`, `set_week`, `held_status`, `held_release_quiz`, `held_discard_quiz`, `attend_status`, `attend_submit`, `attend_discard`, `roster_edit`, `roster_tidy` |
| `quiz-host.html` | Lecturer | Host key | `control` (including `revote`), `host`, `questions`, `setkey` |
| `attendance.html` | Lecturer | Host key | `hostcheck`, `attend_open`, `attend_close`, `attend_status`, `attend_review`, `attend_approve`, `attend_remove`, `attend_phone_reset` (submit and discard are in the Control Centre) |
| `codes.html` | Lecturer | Host key | `hostcheck`, `access_codes` |
| `insights.html` | Lecturer | Host key | `hostcheck`, `insights` |
| `groups.html` | Lecturer and projector | Host key | `groups`, `groups_display` |
| `outcomes.html` | Lecturer | Host key | `outcomes` |
| `assignments.html` | Lecturer | Host key | `assignments` |

## Desktop app (`desktop/`)

| File | Role |
|---|---|
| `main.js` | Electron main process: HTTP server (port 8143), tunnel server, windows, IPC handlers, generated `config.js` and `portal.json` |
| `preload.js` | `window.cmApp`: the fixed IPC bridge |
| `backend.js` | Runs `quiz_receiver.gs` in a Node `vm` with local versions of the Google services; persists `workbook.json` |
| `course.js` | Course folder, lecture page templates, course pack import and export |
| `table.js` | Class list files (CSV, xlsx, paste) |
| `authoring.js` | Resource library, search, summaries, question generation and import, review queue, bank overlay |
| `google.js` | Optional Google sign-in and one-way copy to a Sheet |
| `tunnel.js` | Optional internet address through a Cloudflare quick tunnel |
| `make-course-pack.js` | Builds a course pack .zip from a source folder |
| `app/home.html` | The main window and its ten views |
| `app/insights.js` | Class Overview, Students, Attendance, Quizzes and Questions |
| `app/progress.js` | Learning Progress and the student lookup |
| `app/setup.html` | First-launch setup: course details, class list, materials |
| `app/author.html` | Resources and questions |
| `app/question-template.md`, `.docx` | Template for importing questions |
| `test/` | `stats.test.js`, `pedagogy.test.js` and sample classes (`npm test`, 24 tests) |
| `package.json` | Version, dependencies and the electron-builder configuration |
| `README.md`, `README.txt` | Developer notes; the instructions shipped beside the installers |
