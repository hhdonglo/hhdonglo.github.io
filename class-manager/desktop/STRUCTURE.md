
- `roster-shots/files.js`: class list from any standard file (CSV, Excel, Word, text, PDF text) by reusing `autoload/read-file.js` and `detect.js`.
- `autoload/file-types.js`: the shared list of accepted upload types.

- `desktop/lecture-files/` (`types.js`, `classify.js`, `peek.js`, `describe.js`, `build.js`, `store.js`, `actions.js`, `ipc.js`, `README.md`) decides which files are lecture documents (PDF or Word only), what each is (slides or notes, handout, tutorial, supplement, reference, with a confidence), what is ignored and why, and what the lecturer can open, replace, take off or move to Removed; `app/lecture-viewer.js` shows a document. Test: `test/lecture-files.test.js`. Clicking a lecture card opens the lecture view (`app/lecture-view/`: `state.js` rules, `view.js` the view with Present, `present.js` full screen presentation of the slides PDF, `slide-cache.js` which pages to keep ready and at what size, `slide-show.js` swaps a slide in only once it is drawn so a change never blinks, `slide-renderer.js` draws a page off screen with the bundled PDF reader in `vendor/pdfjs/`, `lecture-view.css`; README there). Tests: `test/lecture-view.test.js`, `test/slide-show.test.js`.
- `lecture-progress/` and `rules/lecture-progress.js`, `rules/lecture-log.js`, `rules/lecture-schedule.js` (due, next and missed lectures), `app/lecture-progress.js`: lectures held against the semester target (see lecture-progress/README.md).

Lecture detection: `desktop/autoload/lecture-names.js` finds lecture numbers in file and folder names (lecture1, Lecture_01, L1, Lec 2, week3, "08 Waves", numbers in folder names) and groups files by lecture, with gaps (one detector, uses the existing folder scan `autoload/scan.js`). `desktop/lecture-files/build.js` first decides which files are real lecture documents and what each is (see lecture-files/README.md), then `desktop/lecture-files/build.js` first decides which files are real lecture documents and what each is (see lecture-files/README.md), then `desktop/lecture-progress/overview.js` merges that with lectures.json and the banks into "Lecture 1" to the last, shown on Course and Content (`app/lecture-list.js`, `app/lecture-viewer.js`, call `cm:lectureOverview`). The last detected number pre-fills "Lectures planned" in Course settings. Tests: `test/lecture-names.test.js`, `test/lecture-overview.test.js`.
