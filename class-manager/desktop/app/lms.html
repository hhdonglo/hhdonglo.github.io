Privacy

Student data stays on this computer. CM contacts a learning management system (LMS) only when the connection below is switched on, and then it sends only the LMS's own user id and the points. Names and other records are never sent. The files in the first two cards need no connection at all.

1. Roster from the LMS

Export the roster from the LMS as CSV or Excel and read it here. CM shows what would change before anything is added. Students already in CM are matched by student ID; names are never overwritten, and nobody is removed.


2. Grades to the LMS

Choose the assessments. A student with no score is left empty, never sent as zero.

3. Direct connection (optional)

Lets CM read the roster and send scores itself, using the standard LTI Advantage services. The LMS administrator registers CM once, using the file below, and gives you the client ID and the three addresses.
