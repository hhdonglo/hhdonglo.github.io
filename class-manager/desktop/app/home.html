How students connect

…

Phones join the same Wi-Fi as this computer, or a phone hotspot that this computer is also connected to. If phones cannot open the address, the network keeps devices apart (common on university Wi-Fi): use a hotspot, or choose Internet. Other addresses of this computer: none.

Students open the https address from any network, including mobile data, while this app is open. The address changes each time it starts, so show the new QR code. Traffic passes through Cloudflare's free quick tunnel service, which offers no uptime guarantee; for a class it is usually enough. The first time, the app downloads Cloudflare's connector program and checks it. The app's own screens are never reachable from the internet, and the lecturer pages still need the host key.
