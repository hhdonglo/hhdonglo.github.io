Engagement rules and thresholds

The effort score is the average of the parts that exist: attendance rate, the share of live quizzes taken, and recent practice (100 if the student practised within the period, otherwise 0). Performance is the live quiz average, or the practice average when no quiz has been taken. The groups are suggestions for you to review. They are never shown to students, and practice counts only when a student entered their ID, so a missing record is a prompt for a conversation, not evidence.

How students connect

Same Wi-Fi or hotspot. Phones join the same Wi-Fi as this computer, or a phone hotspot that this computer is also connected to.

If phones cannot open the address, the network keeps devices apart, which is common on university Wi-Fi. Use a hotspot, or choose Internet.

Internet. Students open the https address from any network, including mobile data, while this app is open. The address changes each time it starts, so show the new QR code.

Traffic passes through Cloudflare's free quick tunnel service, which offers no uptime guarantee; for a class it is usually enough. The first time, the app downloads Cloudflare's connector program and checks it.

The app's own screens are never reachable from the internet. Lecturer pages are refused through the internet address unless you allow them in App Settings, and the address stops by itself after the time set there (3 hours unless you change it).

Courses

Each course has its own class list, attendance, quizzes, groups, assignments, learning objectives, messages, host key and Google Sheet. Nothing is shared between courses. A course's lectures and files are kept in the app, or in a folder you link, such as a copy of a GitHub repository. Student records are never written to a linked folder.
