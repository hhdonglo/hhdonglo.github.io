Check each question, edit it if needed, then approve. Approved questions join the lecture's bank at once: the practice page, the live quiz and the mock examination use them. Questions with an error (shown in red) cannot be approved until it is fixed.

  


  

  

 






 

  
Question banks

  
Questions that come with the course stay as they are. Questions you approve here are kept in the app's data folder and added to the banks the pages read. Withdrawing an approved question returns it to the drafts.

  

 






 

  
Claude (optional)

  
Summaries written by Claude and question generation use an Anthropic API key, which you enter once. It is stored on this computer and sent only to the Anthropic API. Without a key, the library, search, extractive summaries, import, writing questions and approval all work.

  

  


  


  
Keys are created at console.anthropic.com. Use of the API is charged to that account.
