# Question template for Class Manager

Write each question as below. Word (.docx), PDF, Markdown (.md) and plain text files are all read the same way.
Lines before the first question set the lecture, difficulty and type for every question that follows;
a line inside a question overrides them for that question.

Lecture: 5
Difficulty: moderate

Q1. A 2.0 kg book is raised from a shelf 1.0 m above the floor to a shelf 2.5 m above the floor. What is the change in its gravitational potential energy? Take g = 9.80 m/s^2.
A) 49.0 J
B) 19.6 J
C) 29.4 J
D) 14.7 J
Answer: C
Explanation: The change is mg(y_2 - y_1) = (2.0)(9.80)(1.5) = 29.4 J. Only the change in height matters.
Type: calc
Reference: Lecture 5 slides, slide 12

Q2. Which statement about a conservative force is correct?
A) The work it does depends on the path taken.
*B) The work it does around any closed path is zero.
C) It always does positive work.
D) It cannot change kinetic energy.
Explanation: For a conservative force the work done depends only on the end points, so around a closed path it is zero.
Type: concept
Difficulty: easy

Rules
- A question starts with "Q1.", "Q2." (or "1.", "2.", or "Question:").
- Exactly four options, A) to D). "A.", "(A)" and "a)" are also accepted.
- Give the correct answer with "Answer: C", or put an asterisk before the correct option.
- Optional lines: Explanation, Type (concept, calc, graph or misconception), Difficulty (easy, moderate or difficult), Lecture, Reference, Source.
- Superscripts and subscripts: m/s^2, 10^-3, x^{2n}, v_0, v_{max}. The tags <sub>, <sup>, <em> and <strong> may also be used.
- A line of three hyphens (---) may separate questions; it is optional.
