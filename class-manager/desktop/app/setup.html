Class Manager

New course · Course setup

Three short steps set the app up for your course. Each step can be skipped and finished later from the home screen, and everything stays editable.

Course details

These details appear on every page students and you see: the portal, the projector display, the access code slips, the calendar and the exported results.

Appearance and notice (optional)

Class list

Attendance, quiz marks and access codes count only the students on the class list. Choose a file exported from your student records (CSV or Excel), or paste the list. Then say which column holds the student ID and which holds the name, and check the preview before saving.

Course materials

Add your lectures one by one, with their slides, handouts and tutorial sheets. Students then find them on the portal. If a colleague or an earlier year prepared a course pack, import it instead and everything comes in at once.

Course pack (optional)

A course pack (.zip) holds a whole course: details, lectures, files and question banks. Importing one replaces the course content in this app; class records are not touched.

Teaching material and question files

Add PDF, Word, PowerPoint or Markdown files to the library to search them and draft questions from them. Existing question files (Word, PDF or Markdown) are imported for you to review before students see them.
