Class Manager

New course · Course setup

Three short steps set CM up for your course. The class list comes first because everything about students is checked against it, but every step can be skipped and finished later, and CM can be set up without a class list. Everything stays editable.

How do you want to begin?

Start from scratch

Add your class list first (a CSV, Excel, Word, PDF or text file, or a screenshot), then the course details. CM builds everything else: the class list, Master, Scores, Totals and the attendance sheet, ready for the first session.

Use a template

Download a workbook with the right headings, fill in scores or attendance, then load it. It is checked against the class list from the Class roster step; it never adds students.

Load from a folder

Point CM at the folder that holds your files (scores, attendance, quiz bank, in any layout). Students are never added from it: it is checked against your class list. It finds what it needs, ignores the rest and builds a clean working file of its own. Your files are never changed.

Continue from existing data

Load the results exported from the web version (the Google Sheet downloaded as Excel). You read a preview first; scores, attendance and practice attempts for students on your class list are loaded and you carry on from there. Add the class list first, from screenshots.

Course details

Type the course name and the other details here. These appear on every page students and you see: the portal, the projector display, the access code slips, the calendar and the exported results.

CM reads the outline and course files in a folder and fills this form. Everything stays editable.

Appearance and notice (optional)

Class roster

This is the first thing to add. You may skip it: course details and course materials need no class list, but results, attendance, marks and anything else about students can be added only once the class list exists. The class list is the fact the whole course depends on: attendance, marks and access codes count only the students on it. It is entered here and nowhere else. Every other file you add to CM is only checked against this list, and never adds or changes a student.

Add your class list in any standard file: CSV, Excel, Word, text or PDF, in any layout (ID and name columns are found for you, extra columns are ignored), or paste the list as text. These are read on this computer: no key, nothing is uploaded. Only a screenshot or a scanned PDF needs Claude to read it, using your Anthropic API key, and those pages are sent to Anthropic (nothing else about the course is sent). You then check and correct the table before anything is saved. An ID belongs to one student: a repeat is merged, and an ID read with two names must be settled by you.

Course materials

Add your lectures one by one, with their slides, handouts and tutorial sheets. Students then find them on the portal. If a colleague or an earlier year prepared a course pack, import it instead and everything comes in at once.

Course pack (optional)

A course pack (a .zip, or the pack folder itself) holds a whole course: details, lectures, files and question banks. Importing one replaces the course content in CM; class records are not touched.

Course folder (quizzes)

Point CM at the folder that holds your course. CM finds the quiz banks in the format of the quizzes already online (files named lecture1.json, lecture2.json and so on, with the questions inside), checks every question and adds them to the course. Questions already in the course are never changed.

New quizzes written by CM

CM writes new quiz questions from your teaching material, for you to review before students see them. It needs your Anthropic API key.
