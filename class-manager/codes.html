Access codes for My progress

Students open their progress page in the Portal with their student ID and a personal access code. The ID alone is no longer enough, so a classmate who knows an ID cannot see that student's marks. Create a code for every student on the class list, print the slips and hand each student their own slip in class. A code can be replaced at any time; the old one stops working at once.
