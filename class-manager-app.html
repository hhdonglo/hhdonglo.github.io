Class Manager app Beta

A desktop app that helps lecturers run any course from their own computer. This Beta version is not yet fully tested.

What it does

  • Sets up for any course in a few steps: course details, class list and course materials.
  • Live class quizzes, with a projector view and results.
  • Attendance by QR code.
  • Practice questions and a mock exam for students.
  • Each student sees their own attendance, quiz results and progress.
  • Teaching insights, student groups, a course calendar, announcements and class messages.
  • A library of the lecturer's own course files, with search, summaries and help drafting questions.
  • Students join from their phones over the classroom Wi-Fi, a phone hotspot or the internet (internet access is not yet tested in real classes).
  • All records stay on the lecturer's computer and export to Excel.
Download for Windows

Windows 10 or 11, 64-bit.

Installation and instructions are in the README that comes with the app.
