Class Manager app Beta

A desktop app for lecturers: course pages, practice questions, a mock exam, a live class quiz and attendance by QR code, run from the lecturer's own computer.

Beta. This version is not yet fully tested. Keep a copy of class records elsewhere, and report problems through the Contact page.

Download

Download for Windows

Windows 10 or 11, 64-bit.

Version 0.3.0 (Beta). Release notes and all files

What it does

  • Serves the course pages to students' phones over the classroom Wi-Fi or a phone hotspot, with a QR code to join.
  • Can also give students a temporary internet address, through Cloudflare's free quick tunnel service, so that they join from any network while the app is open. This option has not yet been tested in real classes.
  • Runs a live class quiz with a projector view, timed questions, results and review.
  • Takes attendance with a QR code that changes during the session, one mark per student per day.
  • Gives each student a personal access code to see their own attendance, quiz results and practice progress.
  • Shows teaching insights for each question, and forms student groups.
  • Keeps a course calendar that students can add to their own calendars, with announcements and moderated class messages.
  • Builds a library from the lecturer's own PDF, Word, PowerPoint and Markdown files, with search and summaries, and imports or drafts quiz questions for the lecturer to review before use. Drafting questions and full summaries use the lecturer's own Anthropic API key.
  • Keeps attendance, quiz scores and marks on the lecturer's computer, and exports every table as a CSV file for Excel.
  • Needs no account and no setup: the results workbook and the host key are created on first launch.

Installation

The installers are not yet signed, so the system asks for confirmation the first time.

  • Windows: run the installer. If "Windows protected your PC" appears, choose More info, then Run anyway.
  • macOS: open the disk image and drag Class Manager to Applications. The first time, right-click the app and choose Open. If macOS still refuses, open System Settings, Privacy and Security, and choose Open Anyway.
  • Linux: make the file executable and run it.

When the app first starts, allow it to accept network connections on private networks, so that students' phones can reach it.

In class

  1. Open Class Manager and add the class list: student ID, then name if desired, one student per line, or a CSV file.
  2. Connect the computer and the students' phones to the same Wi-Fi. Where the university network keeps devices apart, a phone hotspot works.
  3. Open the Lecturer menu with the host key shown on the home screen, then take attendance or run a quiz.
  4. After class, view or export the Attendance, Master and Totals tables from the home screen.
