Applied & Computational Work

The computational methods behind the research, applied to scientific, real-world and industrial problems.

Modelling nuclear reactions requires numerical simulation, parameter estimation from noisy data, uncertainty quantification and reproducible workflows. These methods are general. This page shows where they are applied beyond nuclear physics, and every area links to the work that demonstrates it.

Areas

Scientific Computing

Numerical modelling, optimisation, simulation workflows and high-performance computing.

Demonstrated in

  • KEWPIE3: a C++ engine for fusion–evaporation reactions, parallelised over beam energies with OpenMP
  • Distributed parameter sweeps: MPI-distributed grids of fits across several hosts

Machine Learning

Predictive modelling and scientific machine learning.

Demonstrated in

  • KEWPIE3 calibration: Bayesian optimisation with a Gaussian-process surrogate of the loss surface
  • RAG chatbot for cultural events: retrieval-augmented generation, evaluated with RAGAS

Data Science

Statistical analysis and quantitative modelling.

Demonstrated in

  • Uncertainty analysis of nuclear reaction models: profile-likelihood confidence regions
  • EduGlobe Insights: exploratory analysis of World Bank education statistics

Data Engineering

Data pipelines, automation, workflow design and scalable data systems.

Demonstrated in

  • Employee sports benefits platform: Airflow, PostgreSQL and Docker
  • Healthcare data migration: CSV to MongoDB with integrity tests
  • KEWPIE3 workflow: one input file drives calculation, fitting and plotting
